## Análise Inicial

Realizei testes exploratórios para compreender o funcionamento do sistema.  
O sistema apresenta uma interface simples e direta, permitindo:
- **Cadastro de cursos**, com campos como:
  - Nome do curso  
  - Descrição  
  - Instrutor  
  - Imagem de capa  
  - Data de início  
  - Data de fim  
  - Número de vagas disponíveis  
  - Tipo do curso (Presencial ou Online)

- **Listagem de cursos**, exibindo as informações cadastradas.  
- **Exclusão de cursos** já cadastrados.


## Decisões para Criação das User Stories

As decisões para criação das **User Stories** foram baseadas na **análise funcional e exploratória** do sistema.  
Durante essa etapa, observei o comportamento atual das principais funcionalidades, identifiquei fluxos de uso esperados e possíveis inconsistências.  

A partir disso, as histórias foram criadas considerando:

- **A visão do usuário final**, priorizando a simplicidade no cadastro e gerenciamento dos cursos;  
- **As boas práticas de QA**, garantindo cobertura de cenários de sucesso e de erro;  
- **Comportamentos esperados**, mesmo quando a aplicação ainda não apresenta essas validações (como mensagens de erro em campos obrigatórios);   

As decisões foram tomadas com foco em **clareza, usabilidade e confiabilidade do sistema**, garantindo que as User Stories representem o que o produto deveria oferecer para o usuário de forma eficiente e intuitiva.
